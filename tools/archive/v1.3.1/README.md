# Archived 1.3.1 host snapshots

These byte-identical snapshots preserve the host interface used by the published 1.3.1 packages. The archival validator imports their protocol constants and compares the packaged tools with these originals.

Use the current tools in the repository's `tools` directory for M300Boot 1.4. These snapshots are audit fixtures; their relative paths assume their original extracted 1.3.1 package layout.

The 1.3.1 firmware ZIPs, original manifests and checksums remain unchanged.
